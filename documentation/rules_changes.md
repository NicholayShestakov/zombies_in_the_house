# Изменения относительно правил оригинала

### Доски

Вырезаны.

### Стартовая клетка

Теперь размера 1x1.

### Карточки с одинаковым принципом

Карточки с одинаковым принципом действия заменены на один одинаковых из видов.

### Имена людей

Заменены на более абстрактные названия профессий. Саша - каратист, Настя - медсестра, Макс - бегун, Надя - полицейский,
Борис - атлет.

### Всеобщее количество фишек жизней

В отличие от оригинала, который формально ограничен 40 штуками, является бесконечным.

### Возможность нахождения других людей среди закрытых карточек при игре меньше, чем впятером

Вырезана.

### Победа

На любой из клеток финиша можно использовать канистру или ключи. Это увеличивает счётчик победных очков. Если счётчик
достигает нужного уровня, то машина (все финишные клетки) моментнально уезжает со всеми, кто был в ней в данный момент.

### Нахождение на одной клетке

На любой клетке может находиться неограниченное количество как людей, так и монстров. Атака будет производиться на
вставшего на клетку последним, то есть на наивысшего.

### Способность бегуна

Просто прибавляется 1 к количеству шагов без возможности выбора.
