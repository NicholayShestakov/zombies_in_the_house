# Как в целом устроен проект

Через GameInitialization мы изменяем изменяемую конфигурацию игры по типу количества игроков и их имён.  
Затем через тот же GameInitialization получаем GameConfig.  
Его мы передаём в функцию start класса GameStarter, который через фабрики создаёт игровую сессию и возвращает
ActionManager.
Всё дальнейшее взаимодействие с игрой происходит получением из ActionManager доступных Action, которые исполняются и
как-либо влияют на игру.
На данный момент при соблюдении условий окончания игры бросается исключение с сообщением об этом, но это временные меры.
